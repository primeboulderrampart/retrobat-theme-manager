## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Theme Catalog** | Browse available RetroBat themes with descriptions and screenshots |
| **Direct Install** | Download and deploy any theme without manual file extraction |
| **Active Switch** | Switch between installed themes from a simple dropdown menu |
| **Backup System** | Save your current theme config before trying a new one |
